JavaScript Events Demo

This page shows basic JavaScript events using simple HTML attributes such as onclick, onchange, onblur, onmouseover, onfocus, onkeyup and onselect.

Event Try it here Result
onload
Runs when the page finishes loading.
 This event runs automatically.
onblur
Runs when the user leaves an input field.
onchange
Runs when the value changes.
onmouseover
Runs when the mouse moves over an element.
 Move the mouse here
onclick
Runs when the user clicks an element.
onfocus
Runs when an input field is selected.
onkeyup
Runs when the user releases a key.
onselect
Runs when the user selects text inside the field.
The result fields are cleared automatically every 6 seconds using setInterval(). You can also clear them manually.
