HTML FORMS - Elements Summary

Type Attributes (example) Example Generic Description
<form> name="f1" Form container Container that groups input elements and allows data submission.
<input type="text"> name="name" Single-line text field for user input.
<input type="password"> name="password" Text field that hides the characters entered (for passwords).
<input type="date"> name="bdate" Input field with a calendar UI for selecting dates.
<input type="radio"> name="gender" Male Female Radio button used to select one option from a group.
<input type="checkbox"> name="terms" Accept Checkbox used to select or confirm an option (on/off).
<select> name="prefix" Dropdown menu that lets users choose one option from a list.
<option> value="33" (inside select) Represents one item inside a <select> dropdown.
<input type="button"> value="Click" Button that performs an action when clicked (does not submit form by default).
id id="xdate" Unique identifier for an HTML element (used in JavaScript or CSS).
name name="email" Identifies the form data key when submitted.
required (no value needed) Specifies that the input must be filled out before submitting the form.
onchange onchange="..." Runs when the value of an element changes.
onclick onclick="..." Runs when an element is clicked.
